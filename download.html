Windows

Windows 10 or 11, 64-bit
Your system

Run the installer: no administrator rights needed. Windows may show a SmartScreen notice the first time, because the app isn't signed; choose More info, then Run anyway.

macOS

macOS 13 or newer, Apple silicon and Intel
Your system

Open the disk image and drag Aniko to Applications. The first time, allow it under System Settings › Privacy & Security › Open Anyway.

Get it on GitHub

Android TV and Fire TV

Plays the libraries your computers share
Your system

On a Fire TV, install the Downloader app, allow it to install unknown apps, and open the APK's address in it. Then turn on Library sharing on a computer with Aniko.

Get it on GitHub

Arch Linux

Built from source with makepkg
Your system

Three commands. Aniko then updates itself with its Update button.

sudo pacman -S --needed base-devel go nodejs npm electron mpv ffmpeg
git clone https://github.com/v0-0x/Aniko aniko
cd aniko/packaging/arch && makepkg -si

Raspberry Pi and other home servers

mediaserver, for a computer that stays on

Shares its library with every Aniko at home, converts video for devices that need it, and keeps them all in step. One install script.

Get mediaserver

The first five minutes

  1. Pick your library folder

    Settings › Local library. Choose the folder with your anime and save: the first scan starts by itself.

  2. Log in with AniList

    Click your avatar, then Log in with AniList. It's optional: without it your list stays on your computer.

  3. Add your TV

    Install Aniko on the TV, then turn on Library sharing under Settings › Other devices on your computer. The TV shows up there.
